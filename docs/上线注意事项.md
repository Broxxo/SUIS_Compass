# 上线注意事项

面向约 **150 人以内** 单校部署（如 Zeabur + Neon/PostgreSQL）。本文档汇总**上线前必须完成**、**上线后立刻测试与调整**、以及**上线后首周建议**事项。与 README 中的功能说明互补，侧重运维与安全。

---

## 一、上线前必须完成（P0）

### 1. 构建与发布产物

- [ ] 在发布环境执行 `npm run build`，**必须零错误**（shared → web → copy → api）。
- [ ] 确认 `apps/api/public/` 已包含最新前端 `dist`（`copy:web` 步骤）。
- [ ] 启动命令：`npm start`（或平台等价命令，运行 `apps/api/dist/index.js`）。

### 2. 前端构建环境变量（生产）

在**构建前端时**写入（Vite 会 bake 进静态资源，运行时无法改）：

| 变量 | 生产值 | 说明 |
|------|--------|------|
| `VITE_USE_CLOUD_STORAGE` | `true` | 必须为字符串 `true`，否则走 localStorage，多用户数据不同步 |
| `VITE_API_URL` | **留空** | 与 API 同源部署时用相对路径 `/api/...`；仅前后端分离时才填完整 API 根地址 |

本地开发可继续 `false`，**上线构建前务必改回并重新 build**。

### 3. 后端运行时环境变量

复制 `apps/api/.env.example` 为生产 `apps/api/.env`（勿提交 Git）：

| 变量 | 要求 |
|------|------|
| `DATABASE_URL` | 生产 PostgreSQL 连接串 |
| `JWT_SECRET` | **≥32 位随机串**，缺失时登录返回 500 |
| `JWT_EXPIRES_IN` | 建议 `7d` 或更短（按校规） |
| `PORT` | 平台注入或 `8080` |
| `SILICONFLOW_API_KEY` | 若需 AI 功能则必填；否则 AI 接口 503，其余可用 |
| `DINGTALK_*` | v0.5.1+ 钉钉学生同步；`DINGTALK_CLIENT_SECRET` 走平台密钥管理，详见 [钉钉学生数据同步.md](./钉钉学生数据同步.md) |

**云上数据库 SSL：** 当前 `apps/api/src/config/database.ts` 中 `ssl: false`。若托管方要求 SSL（Neon 等），上线前需改为按环境启用 SSL，否则可能连不上库。

### 4. 数据库初始化与备份

- [ ] **首次**对空库执行 schema：根目录 `npm run db:init`（执行 `apps/api/src/config/init.sql`）。
- [ ] **已有数据的库**：不要对生产库执行 `docker compose down -v` 式清空；新列依赖 API 首次访问时的 `ensure*` 逻辑或手工对齐 `init.sql`。
- [ ] 在托管控制台配置 **PostgreSQL 自动备份** 与恢复演练方式。
- [ ] 上线后打开「课程设置」保存一次，确认 `course_domains` 等新列无 500（旧库迁移）。

### 5. 安全（上线前必须处理）

#### 5.1 默认系统管理员账号

`init.sql` 种子账号：`Admin` / `Suiscompass2019!`（空库 `db:init` 时写入 `password_hash`，`password` 列为空）。

- [ ] 确认默认 `Admin` 账号已用强密码初始化（v0.5.1+ 为 `Suiscompass2019!`）；勿在公网文档中扩散。
- [ ] 创建真实 `system-admin`，限制测试账号分发。
- [ ] 将 `users.password` 迁移为仅 `password_hash`（bcrypt），**停止在 API 响应中返回 `password` 明文列**（`GET /api/admin/users` 等仍可能返回该字段，需评估后台改密流程）。

可提前在生产库写入 bcrypt 哈希（上线 SQL 或管理脚本），避免首次登录仍用弱口令。

#### 5.2 前端：云端登录失败不得回退本地预设

`apps/web/src/contexts/AuthContext.tsx` 在 API 失败时会回退 `Admin`/`1234`（`lib/users.ts`）。

- [ ] **生产构建前**：移除或仅在 `import.meta.env.DEV` 时启用该 fallback，否则网络抖动或密码错误可能仍以本地预设登录。

#### 5.3 `X-User-Id` 请求头（与 JWT 无关）

后端 `requireUser`：**无有效 JWT 时仍接受 `X-User-Id`**，知道用户 UUID 即可冒充。

- [ ] 公网生产环境 **禁用 `X-User-Id`**（或仅开发环境允许）。
- [ ] 前端 `api.ts` / `authUtils.ts` 生产构建勿发送该头。

> **说明：** 配置 `JWT_SECRET` 并正常登录，**不能**自动关闭此后门；必须单独改代码或环境开关。

#### 5.4 其他密钥与仓库

- [ ] 确认 `.env`、`.env.production` 未提交 Git（已在 `.gitignore`）。
- [ ] 生产 `JWT_SECRET` 与本地、测试环境 **不同**。

### 6. 部署架构核对

推荐：**单服务** Express 同时提供 API + 静态前端（`apps/api/public`）。

```
浏览器 → HTTPS（平台终止）→ Node :PORT
                              ├── /api/*  → Express 路由
                              └── /*      → SPA 静态资源
```

- [ ] 平台健康检查路径：`GET /health`（当前**不检测数据库**，见下文 P1）。
- [ ] 若 API 与前端分域名部署，必须设置 `VITE_API_URL` 并配置 **受限 CORS**（当前 API 默认 CORS 全开放）。

## 二、上线后立刻要做（首日，仍属「必须流程」）

### 1. 冒烟测试清单（真实账号各角色至少 1 个）

| # | 场景 | 预期 |
|---|------|------|
| 1 | `system-admin` 登录 / 登出 | JWT 写入 `localStorage`，刷新后仍登录 |
| 2 | 错误密码登录 | **失败**，且不能出现本地预设 `Admin` 登录成功 |
| 3 | `teacher` 登录 → 课程河流 | 只读/可写符合角色（课程创建仅 system-admin） |
| 4 | `student` 登录 | 仅学生画像/本人报告只读，不能进后台与课程编辑 |
| 5 | 后台：基础设置 → 学段年级保存 | 无 500，`school_settings.grade_structure` 持久化 |
| 6 | 课程设置：课程领域新建/保存 | `course_domains` 正常 |
| 7 | 班级与学生：创建班级、学生、任课 | 数据全校可见、权限正确 |
| 8 | 学业报告：教师填写 → 保存 → 学生查看 | 发布后学生可见 |
| 9 | 课堂助手：积分/分组（若使用） | 云端同步正常 |
| 10 | AI 对话/生成（若启用 key） | 非 503；未配置则确认产品侧已说明 |
| 11 | 课程河流 | 已填学期格子为深色；点开学期不白屏 |

### 2. 立刻调整项

- [ ] **确认 `Admin` 默认密码未泄露**（若 5.1 未完成则立即轮换）。
- [ ] 抽查 `GET /api/admin/users`（管理员 token）：响应是否仍含他人 `password` 字段——若含，限制为内网或改 API。
- [ ] 查看平台日志：启动无 `DATABASE_URL` / `JWT_SECRET` 报错；无大量 401/500。
- [ ] 确认 PostgreSQL 连接数：默认池 `PG_POOL_MAX=80`，勿超过库 `max_connections`。

### 3. 可选但建议首日完成

- [ ] 用预发或低峰对 `npm run load:report` 做一次学业报告压测（见 `tools/load-tests/README.md`），确认 150 人规模下响应可接受。
- [ ] 通知教师：浏览器推荐 Chrome/Edge；清一次旧 localStorage（若曾用本地模式测试）。
- [ ] **v0.6.0 教材目录**：生产库不会自动带上本地写入的语文/数学单元。部署成功后用 system-admin 对生产 API 再跑种子（按课程名匹配，勿用课程 JSON 整包覆盖）：
  ```bash
  SUIS_API_URL=https://<生产域名>/api \
  SUIS_ADMIN_USER='<管理员>' SUIS_ADMIN_PASS='<密码>' \
  python3 tools/curriculum-seed/seed_chinese_pep_g1_9.py
  SUIS_API_URL=https://<生产域名>/api \
  SUIS_ADMIN_USER='<管理员>' SUIS_ADMIN_PASS='<密码>' \
  python3 tools/curriculum-seed/seed_math_g1_9.py
  ```

## 三、上线后首周建议（P1，非首日阻塞）

| 项 | 原因 | 建议动作 |
|----|------|----------|
| JWT 过期 UX | 7 天过期后前端仍显示已登录，写操作失败 | 全局 401 → 清 token、跳转登录 |
| 健康检查 | `/health` 不 ping DB | 增加 `SELECT 1` 或独立 `/ready` |
| 登录限流 | 无 rate limit | 对 `POST /api/auth/login` 限流 |
| CORS | 默认允许所有 origin | 生产配置允许的前端域名 |
| `helmet` | 未使用 | Express 加安全头 |
| 部署文档 | README 偏本地 | 补充 Zeabur/平台：build env、start、备份恢复 |
| 错误边界 | 无 React Error Boundary | 主路由包裹，避免整页白屏 |
| 网络提示 | 云端失败静默用缓存 | 同步失败时顶部提示「未保存到服务器」 |
| pdf.js CDN | 依赖外网 | 改为打包本地 worker（内网/air-gap） |
